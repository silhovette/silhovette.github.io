About

Academic Background

I am an undergraduate student in Artificial Intelligence at Shanghai Jiao Tong University, working on language-model systems with a primary focus on LLM agents, multi-agent systems, and model collaboration.

My research interests center on building capable and adaptive agent systems that can reason, coordinate, and act in complex environments. Recent work spans autonomous agent systems, hierarchical planning and recovery, cross-device interaction, continual learning, and efficient adaptation of large language models.

Research Interests

Topics I Explore

LLM Agents

Building autonomous language-model agents that reason, act, recover from failures, and improve through interaction and feedback.

Planning, Recovery & Adaptation

Studying long-horizon planning, execution-time recovery, and adaptive decision-making under changing intermediate states.

Tool-Augmented Reasoning & Execution

Connecting language-model reasoning with external tools, heterogeneous interfaces, and verifiable execution in real-world environments.

Multi-Agent & Cross-Device Systems

Exploring coordination, delegation, and shared context across agents, models, and heterogeneous devices.

Continual Learning & Model Adaptation

Studying how models acquire new capabilities while preserving prior knowledge through parameter-efficient adaptation and model merging.

Reinforcement Learning

Studying how agents learn, adapt, and retain useful behavior through interaction in continual and non-stationary environments.

Featured Work & Experience

Beyond Global Replanning: Hierarchical Recovery for Cross-Device Agent Systems

Agent Systems

Designed H-RePlan, a hierarchical recovery framework that lets cross-device agents switch API, CLI, and GUI strategies locally before escalating structured failure evidence to the orchestrator for task or device-level replanning.

Agent Systems Long-Horizon Recovery Cross-Device

LLM Continual Learning Research

LLM Adaptation

Investigated parameter-efficient continual learning for language models through replay-free LoRA composition, task-vector structure, and shared/private parameter decomposition for balancing transfer and task isolation.

Continual Learning PEFT Task Vectors LoRA

Dynamic Network Widening for Continual Reinforcement Learning

RL Research

Studied network capacity and mid-training model expansion under hidden environment drift using matched PPO experiments, implementing controlled dynamic widening and evaluating held-out robustness under equal interaction budgets.

Continual Learning PPO Dynamic Network Growth Robustness Evaluation

Multi-Device Agent Orchestration & Verified Execution

Agent Systems

Developed a multi-device agent system for capability-aware task orchestration and reliable execution across heterogeneous devices, integrating API, CLI, and GUI interfaces with execution contracts, evidence collection, and postcondition verification.
