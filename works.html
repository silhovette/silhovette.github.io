Beyond Global Replanning: Hierarchical Recovery for Cross-Device Agent Systems

Agent Systems

Designed and implemented H-RePlan, a hierarchical replanning framework for cross-device agents that separates device-local strategy recovery from orchestrator-level task and device reassignment.

  • Added an LLM-based strategy planner that selects and retries API, CLI, and GUI execution strategies within each device context.
  • Introduced Cross-Layer Failure Events (CLFEs) to compress local execution evidence into structured signals for orchestration-level replanning.
  • Integrated capability-aware strategy bindings, retry budgets, chain history, and partial DAG-result reuse into the MDC/UFO³ execution flow.
  • Built HeraBench fault-injection workflows over Linux and Android devices, covering local, global, and mixed failures across 174 task variants.

Dynamic Network Widening for Continual Reinforcement Learning

RL Research

Conducted a reproducible continual-control study on network capacity and mid-training model expansion under hidden environment drift. Designed matched PPO experiments across multiple network widths, implemented controlled dynamic widening, and evaluated learning efficiency and held-out robustness under equal interaction budgets.

  • Constructed a continually changing CartPole environment with hidden gravity, mass, pole length, force, and friction perturbations.
  • Matched PPO configurations and interaction budgets across network widths, using multiple training seeds and held-out evaluation panels.
  • Compared fixed-width policies with 64→128 mid-training widening under default and literal all-zero initialization.
  • Built a reproducibility pipeline that preserved configurations, checkpoints, RNG and environment states, selection records, plots, and evaluation tables.
