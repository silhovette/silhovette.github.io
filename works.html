OctoNest: Adaptive Cross-Device Execution through Stateful Control

Agent Systems

Proposed OctoNest, a stateful cross-device execution framework that coordinates device-local modality control with orchestrator-level plan and device revision.

  • Uses Device Agents to refine subtasks and select execution modalities as changing conditions are revealed during interaction.
  • Uses an Orchestrator to revise task plans and device assignments from execution feedback.
  • Introduced CAPEBench with 158 instances from 23 cross-device seed tasks and controlled perturbations.
  • Improved Perfect Pass by 18.35 percentage points over the strongest baseline and reduced token cost per Perfect Pass by 39.8%.

ChainLoRA: Geometry-Preserving Task Vector Merging for Continual Learning in LLMs

Continual Learning

Studied ChainLoRA, a replay-free continual parameter-efficient fine-tuning framework that treats forgetting as geometric interference between task updates.

  • Combines chain-updated training with post-stream adaptive SVD merging while keeping historical-state overhead constant.
  • Uses Procrustes adaptation to align a shared carrier with the latest task and separate shared from task-specific components.
  • Adds a one-sided orthogonality proxy and effective-rank penalty to limit inter-task interference and use the task subspace efficiently.
  • Reports strong replay-free results on Large and SuperNI and competitive results on Standard CL.
Continual Learning Replay-Free PEFT Task Vectors Adaptive SVD Procrustes

Dynamic Network Widening for Continual Reinforcement Learning

RL Research

Conducted a reproducible continual-control study on network capacity and mid-training model expansion under hidden environment drift. Designed matched PPO experiments across multiple network widths, implemented controlled dynamic widening, and evaluated learning efficiency and held-out robustness under equal interaction budgets.

  • Constructed a continually changing CartPole environment with hidden gravity, mass, pole length, force, and friction perturbations.
  • Matched PPO configurations and interaction budgets across network widths, using multiple training seeds and held-out evaluation panels.
  • Compared fixed-width policies with 64→128 mid-training widening under default and literal all-zero initialization.
  • Built a reproducibility pipeline that preserved configurations, checkpoints, RNG and environment states, selection records, plots, and evaluation tables.
